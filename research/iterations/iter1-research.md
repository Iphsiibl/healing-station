## 二、源里读到的三件事

### 1）社区当下的焦虑主线是「AI / 行业 / 生计」，不是具体职场小事

知乎热榜前 20 里与生计直接相关的：

| 问题 | 话题 | 热度（pv） |
|---|---|---|
| 如何看待近段时间网络上对国内 llm 的悲观预期？ | LLM / AI | 356.9 万（关注 1327、回答 524） |
| 哪个行业悄悄崩盘了，大家还没有发现？ | 职业 / 教育 / 行业 | 600 万（回答 276） |
| 如何看待 2026 年 11 月 15 日 deepseek 关于对话上限长度的调整？ | AI 技术 | 213.7 万 |
| 深圳目前存在的最大的问题在哪里？ | 深圳工作与生活 | 高（上轮记录） |

热榜整体仍被英伟达 / 黄仁勋系列垄断（相关条目 pv 千万级），**说明「科技乐观 vs 裁员悲观」是同一条新闻的两面**——这正好是打工人这两年最实在的恐惧。

**对产品的含义**：急诊室现有的 8 个心情（累/慌/委屈/气/迷茫/社恐/低落/还不错）都是「情绪词」，缺的是**处境**。用户不会用「我被优化了」这种词搜索情绪，但他会点「被优化了 🕯️」。→ 心情要按处境补，不按情绪补。

### 2）百度民生榜：普通人的愁是「家、身子、通勤、消费」

民生榜（每 5 分钟更新）当天的条目集中在：家庭伦理与父母子女（「28 岁男子抱着刚出生亲弟弟笑不出来」「96 岁父亲经常骑三轮去看 70 岁女儿」）、健康久坐（「久坐男子运动会跑步没有外伤竟骨折」）、气温与通勤（「降温日历来了」）、消费维权（「零元面馆免费面是慈善还是添乱」「顾客称茶颜悦色充值拒收 400 元现金」）、被制造焦虑（「直播间演员冒充家长制造焦虑」）。

**对产品的含义**：这批情绪和「上班」无关，但和**打工人下班以后的生活**有关——久坐、 commuting、气温、父母催、钱。急诊室如果只会处理「工位上的事」，用户下班回家就没人管了。→ 这轮先补「通勤」这个把公司和家连起来的处境；久坐、气温、父母催命留到后续轮次按审查结果补（见 `iter1-audit.md` 的缺口表）。

### 3）同类产品怎么做「情绪 → 动作」

从 iTunes 中国区抓到的三个代表：

- **对圈职场｜职场 1v1 成长陪伴**：把职场问题拆成六类处境——应届生求职 / 跳槽转行 / 谈薪升职 / 职场沟通 / 职业迷茫 / 压力内耗。宣传语里有一句很关键：「**这里不是泛泛的职场鸡汤**，我们更关心的是：你的问题发生在什么处境里，你真正担心的后果是什么，以及下一步可以怎么走。」
- **Winsomely：沟通技巧与高情商**：主打「**在真正重要的对话发生之前，先练一遍**」，可练的场景包含「要求加薪 / 学会拒绝 / 难开口的对话」；坚持机制是「**每天 3 分钟小练习 + 经验值 + 等级 + 连续打卡 + 进步记录**」。
- **读心猫**：上传聊天截图 → 对方态度 / 核心话题 / **可以直接复制的回复** / 关系推进建议。

**对产品的含义（三条可以直接落地）**：
1. **诊断要按「处境」分类**，标题写「被优化了」而不是「焦虑」。
2. **每条处方必须小到 3 分钟能做完**——「今天下午三点前先给您一版框架」这种（大到一天的）可以留，但必须至少有一条是「3 分钟」级别。
3. **不能只给共情，还要给下一步**：像读心猫那样给「可以复制的那一句」，对应我们话术机模块的复制按钮；急诊室这边对应「复诊提醒」——给一句你明天可以直接发给自己的话。

### 4）打卡机制暂时不做，但先留好接口

Winsomely 的「经验值 / 等级 / 连续打卡」和上岸签的「分类打卡 + 行为洞察」都指向同一个需求：**用户要看见自己坚持了几天**。这轮不硬塞进急诊室（会让诊断单变重），但要**在数据结构上留好接口**，等 v1.10.0 的周报 streak / 徽章直接接上。

## 三、本轮结论（补什么，补多少）

| # | 结论 | 依据 | 本轮动作 |
|---|---|---|---|
| C1 | 心情要覆盖「处境」而不只是情绪 | 知乎 AI/行业崩盘信号；「被优化」「被 AI 顶替」是当下最响的两类恐惧 | 心情 8 → 12，新增 `layoff` / `ai_replace` / `commute` / `age_35` |
| C2 | 关键词包要能接住新处境的具体说法 | 用户不会说「被优化」，会说「N+1」「试用期」「绩效」「离职交接」 | 关键词包 10 → 18（裁员、试用期、离职交接、绩效面谈、OKR、远程办公、地铁通勤、租房） |
| C3 | 祝福要「不鸡汤、不说教」 | 对圈职场明说「不是泛泛的职场鸡汤」；现有祝福整体合格但偏少 | 祝福 24 → 60（每种心情 5 条），加进去时坚持「不评价你、不要求你」 |
| C4 | 处方要小到 3 分钟能做完 | Winsomely「每天 3 分钟」 | 每种心情的 4 条处方里，至少 2 条是 3 分钟内可完成的 |
| C5 | 诊断单要给「下一步的一句话」 | 读心猫「可以直接复制的回复」 | 新增 `checkup` 字段（复诊提醒，12 条）+ UI「🩹 复诊提醒」区 |
| C6 | 连续打卡/经验值先不做，但要留接口 | Winsomely / 上岸签 | 本轮不动数据结构以外的字段；streak / 徽章放到 v1.10.0 周报 |
| C7 | 久坐、气温、父母催命属于「下班以后」 | 百度民生榜 | **本轮不做**（超出急诊室「上班中的情绪」定位），记入审计报告缺口表，留后续轮次决定 |

## 四、本轮明确不做的事（避免范围膨胀）

- 不接任何外部 API、不加 npm 依赖、不做「AI 诊断」——急诊室是**本地模板 + 轮转**，不是聊天机器人。
- 不做医疗/心理治疗话术（站点定位是「一个沙发」，不是诊所）；新增文案统一不承诺疗效、不给诊断。
- 不把 4 个新心情做成「大而全」：每个新心情仍然只给 3 诊断 / 3 成因 / 4 处方 / 5 祝福 / 1 复诊，**格式与老心情严格一致**，否则引擎与测试都要重写。
- 不改 `engine.js` 的既有函数签名语义：`diagnose()` 只**新增**返回值字段 `checkup`，旧调用方不受影响。
