# 迭代二调研 · 社恐话术机可以再加什么？

> 时间：2026-11-17 ｜ 目标模块：② 社恐话术机 ｜ 上一版基线：16 场景 × 3 语气 × 3 条 = 144 条

## 一、这次想解决什么

急诊室扩到 12 种心情之后，下一个内容缺口在「话术机」：现在 16 个场景只覆盖了日常小事（改需求、被甩锅、@我、加班…），但**真正让人手心出汗的职场节点**——裁员通知、绩效面谈、年假与病假、年终奖追问、调岗、离职交接——一个都没有；语气也只有「怂 / 稳 / 浪」三档，缺了社恐人群最需要的那一档：**有底气地拒绝**。

调研目标：① 找出还有哪些真实高频的「难开口」场景；② 确认语气应该分几档、每档对应什么说话风格；③ 给「一条话术到底什么时候用、什么时候别用」找到依据。

## 二、源可达性

| 源 | 可达 | 拿到什么 |
| --- | --- | --- |
| iTunes 中国区搜索 API `search?term=职场沟通&country=cn&entity=software&limit=15` | ✅ 200，14 个结果 | 5 个职场沟通类 App 的完整产品描述与更新日志（场景清单、语气分档、回复意图、评分维度） |

| 知乎热榜 API `zhihu.com/api/v4/creators/rank/hot?domain=0&limit=20` | ✅ 200 | 职场相关只有「llm 悲观预期」「哪个行业悄悄崩盘了」「深圳最大的问题」→ 指向**裁员/行业变化**这一类场景，不是话术场景 |

| B 站 API / 维基百科 / itch.io | ❌ | B 站 -352 风控；其余 fetch failed（本轮不作为结论依据） |

> 结论：**具体场景清单的可靠来源是 App Store 中国区的职场沟通类 App 描述**（它们把用户每天在卡壳的场景写得很细），社区热榜只能提供「时代背景」。

## 三、拿到的事实（逐条可核查）

1. **《有底：AI 职场沟通陪练》**（OTTERPAW STUDIO，2026-10 更新）
   - 场景：面试讲清经历和价值、**谈薪时提出期待**、汇报时突出重点、**遇到分歧时表达立场**。
   - 核心理念：「有些对话很重要，值得提前练一遍」；产品形态是一来一回的模拟对话，用来「回应追问」。
2. **《职言 - AI 职场沟通助手》**（2026-03 上架，1.6.5）
   - 语气三档：**简洁 / 专业 / 正式**（简洁用于赶时间的讨论串、专业用于日常、正式用于主管与客户）。
   - 智能回复三档：**接受 / 婉拒 / 缓一缓**（原文大意：先应对，不急着承诺）。
   - 例子：「不好意思我明天没办法去 有事」→ 自动按对象换成得体回复。
3. **《一句顶万句 — 职场恋爱社交高情商话术》**（2026-04 上架）
   - 场景：职场汇报、面试、**拒绝同事**、聚会饭局亲戚追问。
   - 机制：每个场景多种选择、不同回答不同反馈；**结果解析：分析每种回答背后的沟通心理和表达风险**。
4. **Winsomely：沟通技巧与高情商**
   - 可练场景：面试、闲聊、演讲、**谈判、要求加薪、学会拒绝**、与家人朋友同事难开口的对话。
   - 反馈四维度：**清晰度、亲和力、自信、倾听**；并指出「哪句话有效，以及可以换成什么说法」。
   - 机制：每天 3 分钟小练习 + 经验值等级 + 连续打卡（连续打卡那部分留给 v1.10.0 的徽章）。
5. **撩语输入法**：痛点表述是「表达尴尬」「不知道怎么说」「从容自信」→ 用户要的是**说出口的那一句**，不是道理。
6. **Memova AI**：从录音里回看自己「怎么表达需求、怎么给反馈」，并给沟通建议 → 提示话术之前要先有**目的**。

## 四、结论

- **D1 场景扩到 26 个**。新 10 个按「谁在对面 / 什么性质」分成四组，覆盖不同压力源：
  - 不可逆节点：`layoff_notice` 裁员通知、`exit_handover` 离职交接
  - 向上要资源：`leave_request` 年假申请、`sick_leave` 病假条、`transfer_talk` 调岗谈话、`bonus_ask` 年终奖追问
  - 向上/横向守边界：`perf_review` 绩效面谈、`blame_shift` 被甩锅（补强）、`group_mention` 群里被 @（补强）
  - 对外接需求：`client_push` 客户催稿
  → 依据：APP 的场景清单（拒绝同事、要求加薪、谈薪、请假、离职交接是高频交集）+ 知乎「行业崩盘 / llm 悲观预期」带来的裁员与变动焦虑。
- **D2 语气加第 4 档「🔥 直球·有底气」**。依据：Winsomely 把「要求加薪、学会拒绝」单独列为一类；现有三档（怂/稳/浪）没有一档能承担「明确说不」「把好处争取到手」；职言的「婉拒」也说明拒绝类话术需要独立档位。定位：**怂 = 不得罪人，稳 = 专业有边界，浪 = 幽默化解，直球 = 明确表态不背锅**。
- **D3 每个场景补两个短字段**：`when`（什么时候这句话管用）与 `avoid`（别在什么时候说）。依据：「结果解析：分析每种回答背后的沟通心理和表达风险」。
- **D4 话术必须「可复制即用」**：每条 ≤ 60 字、完整句、能直接粘进微信/钉钉；不写「如下」「如上」这类无法独立成立的片段；不出现 Markdown 标记。
- **D5 话术不得承诺结果**（例如「这样一定能涨薪」「肯定会被裁」），只承诺**动作**（「我明天上午把方案发你」）。
- **D6 语气标签要说人话**，UI 上直接标「怂一点 / 稳一点 / 浪一点 / 直球一点」，并给每档一句人话说明，让人知道自己在选什么。

## 五、本轮明确不做

- 不接 AI 在线生成：应用要完全离线、零依赖、可双击打开（与总原则一致）。
- 不做多语言：现有模块一律简体中文。
- 不做「话术效果预测」「成功率评分」：我们只是给句子，不装成教练。
