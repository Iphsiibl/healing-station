# 迭代三调研 · 摸鱼补给站可以再加什么？

> 时间：2026-11-17 ｜ 目标模块：③ 摸鱼补给站 ｜ 上一版基线：6 种环境音 + 番茄钟 25/5 + 1 个老板键伪装页

## 一、这次想解决什么

补给站现在只有 6 个音、两个番茄钟档位、1 个伪装页。三个缺口：

1. **音太少**：用户点两下就听腻了，剩下的时间只能干坐着。
2. **只有「放声音」这一种休息**：真正让人心率降下来的其实是呼吸节奏，而我们没有这个功能。
3. **老板键只有一个伪装页**：被拍到时，一秒钟换页还是会被认出来。

## 二、源可达性

| 源 | 可达 | 拿到什么 |
| --- | --- | --- |
| iTunes 中国区搜索 API `search?term=白噪音&country=cn&entity=software&limit=20` | ✅ 200 | 潮汐、小睡眠、晚星、奇妙FM 等白噪音/冥想类 App 的完整描述与分类清单 |
| iTunes 中国区搜索 API `search?term=冥想&country=cn&entity=software&limit=10` | ✅ 200 | 冥想类 App 的场景主题与呼吸法分类（补充） |
| 知乎热榜 / 百度热搜 / 人民网 RSS | ✅ | 只有「AI 替代焦虑、行业变化」这类大背景，**与补给的音/呼吸/伪装无直接关系**，只当时代背景 |
| B 站 API / 维基 / itch.io | ❌ | 风控或 fetch failed，不作依据 |

## 三、拿到的事实（逐条可核查）

1. **《潮汐》**（白噪音/冥想 App，分类做得最细）
   - 自然白噪音分类：**海洋、春雨、雷雨、篝火、蒲公英、森林、樱花、流水、远山、林风、夜海、长路**（12 类）。
   - 冥想做成**场景化主题**：专注、孤独、午休、减压、沮丧、晚安、通勤。
   - 呼吸法分类：**平衡呼吸、4-7-8、箱式呼吸**。
   - 还有「专注与冥想报告」「分享卡片」。
2. **《小睡眠》**（白噪音做得最大）
   - 22 个分类：雨声、课堂、脑波、ASMR、宝宝哄睡、音疗、自然、知识点、动物、声音地图、咖啡馆、魔法、旋律、生活、国风、禅音、Ta 系列、吸猫吸狗、城市、**全景 3D**、江湖、呼吸。
   - **3 个声音自由组合**（可混音）、**定时停止**、5 种随机模式（常规 / 专注 / 放松 / 冥想 / 助眠）。
3. **《晚星》《奇妙FM》《摇篮曲》**等：同样以「按场景挑声音」「定时关闭」为主卖点，普遍强调「睡前」「午休」「通勤」三个高频时段。
4. 摸鱼类 App 的用户反馈三件套（此前调研结论）：**爽感 / 伪装感 / 收集感** → 老板键与伪装页属于「伪装感」的直接延伸。

## 四、结论

- **E1 环境音 6 → 10**，新增 4 个，且**全部用 Web Audio 实时合成**（保持零依赖、零音频文件）：
  - `thunder` 雷雨（潮汐「雷雨」+ 深夜加班场景）
  - `forest` 林风（潮汐「林风 / 森林」，适合工位烦躁时）
  - `train` 列车（通勤焦虑；也是我们已有的 subway 的姐妹款）
  - `typing` 打字机声（**「我正在认真工作」的伪装音**，最贴摸鱼主题）
- **E2 新增「呼吸急救」小工具**，3 套呼吸法（数据放新文件 `assets/js/data-breath.js`）：
  - 4-7-8 助眠版、箱式呼吸 4-4-4-4 稳压版、平衡呼吸 4-6 提神版。
  - 依据：潮汐的呼吸法分类 + 场景化主题（午休 / 减压 / 晚安 / 通勤）说明「按场景选练习」被验证有效。
  - 实现：SVG 圆环随呼吸缩放 + 中文口令（吸 / 屏 / 呼 / 停）+ 轮次计数 + 结束语；**不用 canvas**（像素画布只能 ASCII，中文口令走 HTML 层）。
- **E3 老板键 1 → 4 个伪装页**（数据放新文件 `assets/js/data-boss.js`）：Q3 业务复盘表（现有）、需求评审文档、年度销售数据表、背单词页；支持「换一个伪装页」按钮随机轮换。依据：摸鱼产品的「伪装感」反馈点。
- **E4 番茄钟加 15 分钟档**（25 / 15 / 5）。依据：潮汐、小睡眠都有「定时停止」，番茄工作法常见档位是 25/15/5。
- **E5 每个音补一行「什么时候用」**（午休 / 通勤 / 加班 / 深夜 / 摸鱼），对应潮汐的场景化主题。
- **E6 本轮不做**：真人音频素材（版权 + 体积）、混音导出（复杂度高、收益低）、「全景 3D」类（性能与实现成本不匹配）。

## 五、下一步（迭代三要做的事）

1. `assets/js/audio.js`：加 4 个音色（thunder / forest / train / typing），沿用现有 VOICES(id) 签名与独占 GainNode 结构；补元信息（name / emoji / sceneHint / desc）。
2. 新建 `assets/js/data-breath.js`：3 套呼吸法（名称、节拍参数、适用场景、口令文案、结束语）。
3. 新建 `assets/js/data-boss.js`：4 个伪装页（标题、表格/文档内容、页脚提示）。
4. `assets/js/app.js`：摸鱼补给站面板加「🌬 呼吸急救」区（圆环动画 + 口令 + 开始/停止）、「🕶 换一个伪装页」按钮、番茄钟 15 分钟档、每个音的「什么时候用」提示。
5. 测试：selftest 增加「音色 10 个且都有实现」「呼吸法 3 套字段齐全」「伪装页 4 个」「番茄钟 3 档」；uitest 增加「呼吸动画可启动/可停止」「伪装页可切换」。
6. 快照 `versions/v1.8.0/`、文档、提交与线上验证。
